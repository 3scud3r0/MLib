# MLib — ML-MATHLIB 0.5

Biblioteca experimental de matemática exata e certificação computacional em Python puro.

```bash
python ml_mathlib.py --test-all
```

Leia o [guia 0.5](README_MLIB_0_5.md) e a [auditoria de 25 limitações](CHECKLIST_25_0_5.md). A presença de uma prova Lean não substitui sua compilação pelo kernel Lean 4.

O desenvolvimento 0.6 acrescenta instalação via pip, sistemas lineares
retangulares certificados, expressões analíticas integradas e descoberta esparsa.
Veja o [guia de uso](README_MLIB_0_6.md) e o
[escopo implementado e pendências](IMPLEMENTATION_STATUS.md).
